# Inazuma Eleven DS Recruitment Limit Expansion

This patch increases the maximum number of recruitable players in the Nintendo DS versions of the Inazuma Eleven series.

## New Recruitment Limits

| Game | Maximum Players |
|------|------:|
| Inazuma Eleven | 200 |
| Inazuma Eleven 2: Fire / Blizzard | 200 |
| Inazuma Eleven 3: Spark / Bomber | 300 |
| Inazuma Eleven 3: The Ogre | 400 |

## Additional Features

### Inazuma Eleven

To support the increased player capacity, the reserve player list has been expanded.

- Press **R** to cycle through additional reserve player pages.
- This allows access to players recruited beyond the original limit.

## Notes

- Save files created before applying this patch are not compatible.
- A new save file is required.
- Back up your original save data before use.
- Use at your own risk.
