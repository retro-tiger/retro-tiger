# Inazuma Eleven DS Recruitment Limit Expansion

A patch for the Nintendo DS versions of the Inazuma Eleven series that increases the maximum number of players that can be recruited.

## Supported Games

### Inazuma Eleven
- Recruitment limit increased to **200 players**

### Inazuma Eleven 2: Fire / Blizzard
- Recruitment limit increased to **200 players**

### Inazuma Eleven 3: Spark / Bomber
- Recruitment limit increased to **300 players**

### Inazuma Eleven 3: The Ogre
- Recruitment limit increased to **400 players**

## Important Notes

- Save data transfer between games is currently **not supported**.
- Please back up your save data before applying the patch.
- Use at your own risk.
