# Game Preservation Patches

Many older games contain bugs, hardware-related issues, or progression blockers that were never fixed. As original hardware continues to age and become less reliable, some of these problems make it increasingly difficult for players to experience the games as intended.

This repository provides patches that address such issues and help preserve these games for future generations. These patches may fix software bugs, remove unnecessary hardware dependencies, or restore features that have become difficult to access due to aging peripherals.

The aim is not to alter the original experience unnecessarily, but to restore playability where technical problems prevent normal progression or access to game content.
