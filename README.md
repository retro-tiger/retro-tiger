# Game Preservation Patches

Many older games contain bugs, hardware-related issues, or progression blockers that were never fixed. As original hardware continues to age, some of these problems make it increasingly difficult for players to experience the games as intended.

This repository provides patches that address such issues and help preserve these games for future generations. The aim is not to alter the original experience unnecessarily, but to restore playability where technical problems prevent normal progression.

All patches are provided as-is and should be used at your own risk.
