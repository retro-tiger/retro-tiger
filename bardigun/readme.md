# Barcode Battler Bardigun Bug Fix Patch

This patch fixes several progression-related bugs in Barcode Battler Bardigun.

## Fixed Issues

- The game could become stuck after clearing Story Episode 1 until a seasonal event was completed.
- Completing the seasonal events on December 31, January 2, or January 3 could incorrectly advance the main story.

## Notes

- Use at your own risk.
- A separate patch is available to improve story pacing. That patch triggers either a story event or a seasonal event every day instead of advancing the story only once per week.
- Only one patch should be applied at a time.
