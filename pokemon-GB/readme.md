# Pokémon Team Rocket Patches

Unofficial add-on patches that allow you to play as Jessie or James from Team Rocket in Pokémon Yellow, Red, Green, and Blue.

These patches are designed to be applied on top of the corresponding **Catch All 151 Pokémon Edition Full Color patch** created by yyoossk.

## Supported Games

Patches are available for the Japanese versions of:

- Pokémon Yellow
- Pokémon Red
- Pokémon Green
- Pokémon Blue

Each Team Rocket patch must be applied to the corresponding game after applying yyoossk's compatible Catch All 151 Pokémon Edition Full Color patch.

Do not apply a patch made for one game to a different game.

# Features Available in All Versions

## Jessie Version

- Changes the player character to Jessie.
- Changes the rival to James.

## James Version

- Changes the player character to James.
- Changes the rival to Jessie.

## Catch Opposing Trainers' Pokémon

The patches allow you to catch Pokémon belonging to opposing Trainers.

When you successfully catch an opposing Trainer's Pokémon:

- Your Pokémon will still receive experience points.
- The battle will continue after the Pokémon is caught.

## Optional Dialogue Patch

An optional dialogue patch changes selected dialogue to better match the Team Rocket theme.

The dialogue patch can be applied after the selected Jessie or James patch.

# Pokémon Yellow

## Available Main Patches

Choose and apply only one of the following main patches:

### Jessie Version

- Changes the player character to Jessie.
- Changes the rival to James.
- Allows you to catch opposing Trainers' Pokémon.

### James Version

- Changes the player character to James.
- Changes the rival to Jessie.
- Allows you to catch opposing Trainers' Pokémon.

### Jessie Version with Meowth-Style Follower

- Includes all features from the Jessie Version.
- Changes the appearance of the following Pikachu into a Meowth-style Pokémon.

### James Version with Meowth-Style Follower

- Includes all features from the James Version.
- Changes the appearance of the following Pikachu into a Meowth-style Pokémon.

The Meowth-style follower versions already include the corresponding character changes.

Do not apply a standard character version and a Meowth-style follower version together. Choose only one main patch.

Please do not expect highly polished follower graphics, as the sprites were created mainly for fun.

The Meowth-style follower versions also include a small post-game bonus. Play through the game to discover it.

## Required Base Patch for Pokémon Yellow

The Pokémon Yellow patches must be applied on top of yyoossk's compatible:

**Pokémon Yellow Full Color, Catch All 151 Pokémon Edition, Original Generation I Graphics Edition v1.3**

For details about the required base patch, visit:

[Pokémon Yellow Full Color Patch by yyoossk](https://yyoossk.blogspot.com/2026/10/blog-post_364.html)

Other Full Color editions and versions are not currently supported.

## Recommended Patch Order for Pokémon Yellow

1. Prepare a clean ROM image dumped from your own Japanese Pokémon Yellow cartridge.
2. Apply yyoossk's compatible Catch All 151 Pokémon Edition Full Color patch.
3. Choose and apply only one Team Rocket main patch:
   - Jessie Version
   - James Version
   - Jessie Version with Meowth-Style Follower
   - James Version with Meowth-Style Follower
4. Apply the optional Pokémon Yellow dialogue patch if desired.

Do not apply multiple main patches to the same ROM.

# Pokémon Red, Green, and Blue

Team Rocket patches are also available for the Japanese versions of Pokémon Red, Green, and Blue.

These patches must be applied on top of yyoossk's corresponding **Catch All 151 Pokémon Edition Full Color patch** for each game.

## Available Main Patches

For each game, choose and apply only one of the following:

### Jessie Version

- Changes the player character to Jessie.
- Changes the rival to James.
- Allows you to catch opposing Trainers' Pokémon.

### James Version

- Changes the player character to James.
- Changes the rival to Jessie.
- Allows you to catch opposing Trainers' Pokémon.

## No Follower Versions

Pokémon Red, Green, and Blue do not originally have a following Pokémon feature.

Therefore, Meowth-style follower versions are not available for these games.

Only the following are available:

- Jessie Version
- James Version
- Optional dialogue patch

## Required Base Patches

Before applying a Team Rocket patch, apply the corresponding Catch All 151 Pokémon Edition Full Color patch created by yyoossk:

- Pokémon Red Team Rocket patch requires the Pokémon Red Catch All 151 Pokémon Edition Full Color patch.
- Pokémon Green Team Rocket patch requires the Pokémon Green Catch All 151 Pokémon Edition Full Color patch.
- Pokémon Blue Team Rocket patch requires the Pokémon Blue Catch All 151 Pokémon Edition Full Color patch.

Do not apply a patch to a different game.

For example:

- Do not apply the Pokémon Red patch to Pokémon Green or Blue.
- Do not apply the Pokémon Green patch to Pokémon Red or Blue.
- Do not apply the Pokémon Blue patch to Pokémon Red or Green.

## Recommended Patch Order for Red, Green, and Blue

1. Prepare a clean ROM image dumped from your own Japanese Pokémon Red, Green, or Blue cartridge.
2. Apply yyoossk's corresponding Catch All 151 Pokémon Edition Full Color patch for that game.
3. Apply either the Jessie Version or James Version made specifically for that game.
4. Apply the matching optional dialogue patch if desired.

Choose only one main character patch.

Applying the patches in a different order or using a patch made for another game may cause unexpected behavior.
